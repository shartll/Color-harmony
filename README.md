# Color-harmony
A generator of harmonious color palettes

[Live demo] (https://shartll.github.io/Color-harmony/)

## Opportunities
- Palette generation based on 4 types of harmony (analogous, triad, complementary, split‑complementary)
- Automatic assignment of roles to colors (accent, light, dark, neutral)
- Animations using GSAP

## Stack
HTML, CSS, JavaScript, GSAP

⚠️ Optimized for desktop; the screen may display incorrectly on mobile devices.
